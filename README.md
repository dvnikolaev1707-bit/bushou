# 🎋 Bùshǒu 部首

**Интерактивное приложение для изучения 214 ключей Канси**

Запоминай иероглифические радикалы через живую анимацию черт, spaced repetition и красивый дизайн с двумя темами.

---

## ✨ Возможности

### 📚 База знаний
- Все 214 ключей Канси с пиньинем, значением и мнемоникой
- Разбивка на 3 тира по частотности (ядро → частые → редкие)
- Примеры иероглифов для каждого ключа

### 🎨 Интерфейс
- Две темы: светлая (рисовая бумага) и тёмная
- Адаптивный дизайн: телефон, планшет, десктоп
- Плавные анимации и переходы
- Горячие клавиши (Space, 1, 2, Esc)

### 🧠 Обучение
- **Живая анимация** порядка черт (Hanzi Writer)
- **Интерактивная обводка** пальцем или мышкой
- **Spaced Repetition System** — 5 коробок Лейтнера
- Флип-карточки с эффектом печати при верном ответе
- Умный выбор карточек: просроченные → незнакомые → новые

### 📊 Прогресс
- Кольцо прогресса с процентом выученных ключей
- Разбивка по тирам (видно, что ядро закрывается быстрее)
- Серия дней подряд
- Взвешенное покрытие частотных иероглифов

### 🔍 Фильтры и поиск
- Поиск по пиньиню, значению, номеру ключа
- Фильтры: все / тир 1-3 / выучено / не начато
- Дебаунс 200 мс для плавного ввода

### 💾 Данные
- Сохранение в localStorage
- Экспорт прогресса в JSON-файл
- Импорт с проверкой и санитизацией
- Два варианта сброса: мягкий (сохранить выученное) и полный

## 🎯 Использование

### Главный экран
- **Кольцо прогресса** — сколько выучено
- **Разбивка по тирам** — видно, что ядро (Тир 1) закрывается быстрее
- **Кнопка «Тренировка»** — 10 карточек по расписанию
- **Кнопка «Все 214 ключей»** — сетка с фильтрами и поиском
- **Экспорт / Импорт** — сохранить прогресс в файл
- **Два варианта сброса:**
  - Мягкий: оставить выученное, сбросить расписание
  - Полный: обнулить всё (тема выживает)

### Экран списка
- **Фильтры:** все / тир 1, 2, 3 / выучено / не начато
- **Поиск:** по пиньиню (`shui`), значению (`вода`), номеру (`85`)
- **Клик по ключу** → карточка с деталями

### Карточка ключа
- **Анимация порядка черт** (кнопка «▶ Черты»)
- **Интерактивная обводка** (кнопка «✍️ Обвести»)
- **Мнемоника** для запоминания
- **Примеры** иероглифов с этим ключом
- **Кнопка «Отметить выученным»** → ключ уходит в расписание повторений
- **Навигация** стрелками (← →) или свайпом

### Тренировка
- Показывается иероглиф, нажми Space для переворота
- Оцени себя: «Забыл» (1) или «Помню» (2)
- Верный ответ → эффект красной печати 印
- В конце сессии — итоги (сколько верных, когда следующее повторение)
- Горячие клавиши: Space (флип), 1 (забыл), 2 (помню), Esc (выход)

## 📊 Алгоритм Spaced Repetition

Используется система Лейтнера с 5 коробками:

| Коробка | Интервал повторения | Следующая при верном ответе |
|---------|---------------------|----------------------------|
| 0 (новый) | сразу | → 1 |
| 1 | 1 день | → 2 |
| 2 | 3 дня | → 3 |
| 3 | 7 дней | → выучен |
| выучен | 30 дней | остаётся выученным |

При неверном ответе карточка опускается на одну коробку назад (но не ниже 0).

**Выбор карточек для тренировки:**
1. Просроченные (due < сейчас)
2. Незнакомые из низких коробок (0, 1)
3. Новые ключи по порядку номеров

**Взвешенное покрытие:**  
Тир 1 (ядро) весит × 3, Тир 2 — × 1.5, Тир 3 — × 0.4.  
Так прогресс отражает реальное покрытие частотных иероглифов, а не просто соотношение 47/214.

## 🐛 Найденные и исправленные баги

### Двойной клик в тренировке
**Проблема:** Между ответом и появлением следующей карточки есть пауза 620 мс, но кнопки оставались активными. Повторный клик обращался к `deck[di]` за границей массива → `Cannot read properties of undefined`.

**Решение:** Добавлена защёлка `busy`, которая блокирует ввод на время перехода. Тест на двойной клик подтверждает, что `di` не перескакивает.

### Импорт битых данных
**Проблема:** Номера ключей вне диапазона 1..214 или нечисловые коробки ломали расчёты stats() — `NaN` в процентах.

**Решение:** Импорт санитизирует данные: отбрасывает невалидные номера, приводит коробки к диапазону 0..5, заменяет нечисловые значения на дефолтные. Тест проверяет, что битый файл не роняет состояние.
