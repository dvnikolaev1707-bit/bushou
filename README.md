# Bùshǒu 部首 — интерактивное приложение для изучения 214 ключей Канси

Веб-приложение для изучения иероглифических ключей (радикалов) китайского языка с интерактивной анимацией, спaced repetition и красивым дизайном в двух темах.

## 🎨 Особенности

- **214 ключей Канси** — полная база с пиньинем, мнемониками и примерами
- **Два режима темы** — светлая (рисовая бумага) и тёмная (ночной режим), переключение одним кликом
- **Анимация черт** — живая визуализация порядка черт иероглифов через Hanzi Writer
- **Режим обводки** — учись писать, обводя иероглифы пальцем/мышкой
- **Spaced Repetition** — интервальное повторение по формуле SM-2
- **Колода дня** — случайные карточки с flip-анимацией
- **Сетка всех ключей** — быстрый поиск по номеру тира
- **Мобильный-первый** — адаптивный дизайн, работает на телефонах, планшетах и ПК

## 🎯 Использование

### Главный экран
- **🗺️ Свиток** — сетка всех 214 ключей, отсортированы по тирам
- **🎋 Стрик** — счётчик дней непрерывного обучения
- **🔥 Прогресс** — визуальный индикатор выученных ключей

### Экран ключа
- **▶ Черты** — анимирует порядок черт иероглифа
- **✍️ Обвести** — режим обучения: обведи символ в правильном порядке
- **Мнемоника** — история для запоминания
- **Примеры** — иероглифы, содержащие данный ключ

### Колода дня
- **Флипкарточки** — нажми, чтобы увидеть пиньинь и перевод
- **Помню/Забыл** — оцени свой прогресс
- **Печать-штампер** — визуальный эффект при правильном ответе

### 🌓 Переключение тем
Кнопка в правом верхнем углу (🌓) переключает между:
- **Светлая** — кремово-белая рисовая бумага, чёрный текст
- **Тёмная** — глубокий графит, белый текст

Выбор сохраняется в `localStorage`.

  }

## 🎓 Тиры сложности

- **Тир 1** (красный) — 50 ключей, покрывают 80% иероглифов
- **Тир 2** (зелёный) — 80 ключей, часто встречаются как компоненты
- **Тир 3** (золотой) — 84 ключей, редкие, для полноты

## 💾 Сохранение прогресса

Приложение хранит прогресс в `localStorage`:
- Выученные ключи
- Последний день тренировки
- Выбранная тема
- История повторений (для SRS)

**Важно:** Данные удалятся при очистке браузером кэша!

Для постоянного сохранения используй `localStorage` → `backend` интеграцию (Firebase, Supabase, etc).
