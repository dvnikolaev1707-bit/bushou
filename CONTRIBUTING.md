## Как начать

1. **Форкни репо** на GitHub
2. **Клонируй** свой форк:
   ```bash
   git clone https://github.com/yourusername/bushou.git
   cd bushou
   ```
3. **Создай ветку** для своей фичи:
   ```bash
   git checkout -b feature/awesome-feature
   ```
4. **Сделай изменения** и коммитьте:
   ```bash
   git commit -m "Add awesome feature"
   ```
5. **Запушь** в свой форк:
   ```bash
   git push origin feature/awesome-feature
   ```
6. **Открой Pull Request** в основной репо

## Рекомендации

### Код
- Используй **ванильный JavaScript** (без фреймворков)
- Следи за **совместимостью браузеров** (Chrome, Firefox, Safari, Edge)
- Комментируй сложные части кода
- Используй **CSS переменные** (--var) для значений

### Данные (radicals_data.json)
- Добавляй **настоящие мнемоники**, которые помогают запомнить
- Включай **реальные примеры** иероглифов с этим ключом
- Проверяй **пиньинь** (тоны) в авторитетных источниках
- Уважай **авторские права** — используй только публичные источники

### Текст / Документация
- Пиши на **чистом, понятном русском**
- Используй **эмодзи** для визуального разделения
- Проверяй **орфографию**
- Обновляй **README** при добавлении фич

### Дизайн / UX
- Соблюдай **текущую палитру цветов**
- Тестируй на **мобильных устройствах**
- Убедись, что работает в **обеих темах** (светлой и тёмной)
- Используй **существующие компоненты** (кнопки, карточки)

## Примеры вкладов

### Логичные вклады:
- ✅ Добавить мнемоники для оставшихся ключей
- ✅ Исправить опечатки / ошибки в пиньинь
- ✅ Улучшить UX (лучший поиск, фильтры, сортировка)
- ✅ Написать тесты
- ✅ Оптимизировать производительность
- ✅ Перевод на другие языки
- ✅ Значки и иллюстрации

### Требуют обсуждения в Issue:
- Крупные изменения архитектуры
- Добавление зависимостей (npm пакетов)
- Коренные изменения дизайна
- Новые экраны / режимы

## Тестирование

1. Открой приложение в **разных браузерах**
2. Проверь на **мобильном** (DevTools → Toggle device toolbar)
3. Тестируй **обе темы** (светлая и тёмная)
4. Убедись, что **JSON загружается** правильно
5. Проверь **все экраны** (Home, Card, Train)
